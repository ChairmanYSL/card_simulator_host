## 1. 修改清单

### C1 K1 协议常量改为 1.2
- 文件：ProtocolMessages.java:18（PROTOCOL_VERSION）。
- 改动：值由 1.1 改为 1.2；信封 v=1 不变（ProtocolMessages.java:16）；握手帧写入处（:51）自动跟随。
- 测试：ProtocolMessagesTest、TcpTestClientTest 中 1.1 断言改为 1.2。
- 验收：单测全绿；卡端握手后 host 日志出现 handshake ok: ... protocol=1.2。

### C2 K2 device_config 兼容分支（不改）
- 依据 host 裁决：保留兼容分支，收到旧 device_config 仍 ack，无副作用。
- 卡端心跳仍用缺省 10s / 判死 30s / ack 15s；不需要删除 applyDeviceConfig。
- 测试：现有 device_config 兼容测试保留。

### C3 K3 trace_enabled 改从 card_config 读
- 文件：TestSessionController（handleCardConfig 分支；现状只在 handleConfigPush 的 device_config 分支处理）。
- 改动：在 handleCardConfig() 中读取 trace_enabled（缺省 false；非布尔则 false 并 Timber.w）；必须在 onCaseContext.accept(contextJson()) 之前赋值（contextJson :264 已输出 trace_enabled）。
- 链路：TestClientService.applyCaseContext() 到 ApduEventBridge.setCaseContext(..., enabled) 现成；ApduEventBridge 在 enabled=false 或 caseId 为空时跳过，不上报。
- device_config 兼容分支保留，优先级以 card_config 为准（K3）。
- 测试：新增/扩展单测，断言 card_config.trace_enabled=true 时上报、false 时不上报、非布尔按 false。
- 验收：L5 --trace-enabled 下 trace/<case>.jsonl 4 行；关闭时 0 行。

### C4 K4/K10 session_abort
- 文件：TestSessionController.handleMessage()（现状 default 分支只 Timber.w，不 ack）。
- 改动：新增 case session_abort：
  1. 先 ack {ok:true, detail:session_abort}，无论当前是否 emulating；
  2. 复用 handleStopEmulation() 的停止动作：emvKernel.reset()（保留 AID/profile，H9）、noResponseFilter.resetSession()、清空 case 上下文；
  3. 幂等：重复 session_abort、与 stop_emulation 组合或乱序到达，均不报错、不重复副作用；
  4. 按 host 裁决 3.2(b)：只 ack + 静默停止，不补 status{stopped}；
  5. reason/action 落本地 Timber 日志备查；case_id/attempt_id 仅日志比对，不做归属判定。
- 验收：host L3 早期失败路径卡端日志出现被消费记录；session_abort 单独到达也能停止 HCE；无异常/重复副作用。

---

### C5 K6 坏帧累计计数
- 文件：TcpTestClient.readerLoop()（现状每帧解析成功即 badFrames=0，即连续 5 才断）。
- 改动：去掉成功帧的 badFrames=0，改为累计计数；BAD_FRAME_LIMIT=5 保留。
- 两类区分：
  1. JSON 非法（长度前缀合法）：badFrames++，跳过继续读；累计满 5 才断连；
  2. 长度非法（声明长度大于 1 MiB，或读到的长度值非法）：立即断开，不计入累计 5；落一条 frame_decode_error 日志。
- 验收：L4_1 注入 5 个长度合法 + JSON 非法帧，前 4 个后仍能处理正常帧，第 5 个才断；不存在长度非法帧的误判。

### C6 K7 ready.registered_aids（不改）
- host 裁决 3.1=c：ready.registered_aids 保持 []；host 不以该字段为判据。
- emulating.registered_aids 保持真实注册结果；host 将增加日志记录（H-LOG）。
- 卡端不改代码；ready 四字段保留：profile_id / default_payment_app / registered_aids / ac_crypto。

### C7 无改动项
- K5 stop_emulation ack/status{stopped}：已实现，仅补幂等测试。
- K8 app_version：已用 BuildConfig.VERSION_NAME，构建后回填。
- K9 profile/keys 契约：不变。
- K11 trace 格式：不变。
- K12 APDU 行为：零变化；红线集合 = VISA-CL-001/002、UPI-CL-002、OPBD-001-01、DISC-CL-001。
